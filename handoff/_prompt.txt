# 任务：定位并修复「界面整片白」（Android WebView）

## 你的角色

独立诊断者。不要直接改 `main` / `release-1.2`，在 `codex/white-screen` 分支上给方案与补丁。
先读 `handoff/PROTOCOL.md`。

## 现象

一台 Honor MagicOS 8.0 / Android 14 / 天玑 8000 / 12 GB（型号 SDY-AN00，WebView 版本未知）。
用户打开 App 后，界面**整片白**，什么都点不到；杀掉进程重进，有时正常、有时仍白。

**关键证据**：白屏发生时，App 自己的诊断日志显示页面逻辑完全正常——

```
[layout] ready | {"viewport":"370x776","visual":"370.15x776","doc":"370x776",
                  "root":"370x776","rootChildren":1,"bodyText":264,
                  "bg":"rgb(255, 255, 255)","color":"rgb(15, 17, 21)","dpr":3.25}
[settings] 提交 API Key，开始校验 → 校验通过，写入设置 → 设置已写入
[layout] resize | ... bodyText:60 ...      ← 60 字 = 正常欢迎页（实测对照：有 Key 60 字，无 Key 264 字）
[native] onPause → onStop → visibility:visible → onPause → onStop → onCreate …（反复切后台/重进）
```

也就是说：`#root` 有子节点、尺寸 370×776 正常、文本量正常、前景背景色正常——**DOM 与布局都对，屏幕上却是白的**。

同一位用户的另一条事实：**官方 chat-demo 网页版在浏览器里能正常用**；
把**官方前端原样**套进我们的 Android 外壳（同一个 `MainActivity`）打成的 APK，**同样白屏**。

## 已经试过、无效的改动

1. 移动端框架高度补 `100vh` 兜底（怀疑老 WebView 不认 `dvh`，`height` 退化成 `auto` 塌成 0）
2. 去掉全部常驻 `will-change: transform`（怀疑整页合成层在 `onStop → onResume` 后不重绘）
3. 移除整屏 `backdrop-filter`
4. 原生：显式 `web.setLayerType(View.LAYER_TYPE_HARDWARE, null)`
5. 原生：`web.onPause()` / `web.onResume()` + `resumeTimers()` + `invalidate()`
6. 原生：从后台回来时把 WebView `INVISIBLE → VISIBLE` 重挂一次

以上全部在 1.2.11 里，用户反馈**仍然白屏**。

## 外壳的技术事实

- `MainActivity` 内嵌 `WebView`，`setContentView(web)`，页面由**本地 HTTP 服务**提供：`http://127.0.0.1:8731/index.html`，资源从 APK 的 `assets/web` 读出
- `web.setBackgroundColor(Color.WHITE)`；`hardwareAccelerated="true"`（manifest 应用级）；`largeHeap="true"`
- 前端是 React 18 + rspack 产物的 SPA，`#root` 一个根节点
- 移动端布局：`.frame { position: fixed; top: var(--app-viewport-top,0); height: var(--app-viewport-height, 100vh) }`，`--app-viewport-height` 仅在输入框聚焦时由 JS 赋值
