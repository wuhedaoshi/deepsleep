Deepsleep 1.3.25 使用教程
=======================

一、第一次配置
--------------
1. 安装 Deepsleep-1.3.25.apk。若希望继续使用 DeepSeek，可在「设置 → 数据管理」
   填写 DeepSeek API Key。选用其他服务时，到对应项目填它自己的 Key。
2. 打开「设置 → 实验线设置 → 请求模式」，选择「标准 API」。
3. 展开「服务提供商」，选择要配置的服务。选好提供商、填完该项参数后点「保存」。
4. 先关闭输入框里的「联网搜索」，发一条短消息验证聊天。
   再开启联网，分别用关键词和公开网址测试搜索与读链接。

全家桶：使用 DeepSeek 的扩展功能，包括按需联网、自动标题与安全检查设置。
标准 API：可以为五项服务独立选择提供商。默认各项仍使用 DeepSeek。
切回全家桶会暂时停用自定义配置。再次切回标准 API 可以继续使用原配置。

二、服务提供商里的字段
----------------------
提供商
  决定本项请求发给谁。预设会填好基础地址；选「自定义」才能填写自己的地址。
  想把某一项改回原样，选 DeepSeek 再点「保存」。该项会使用数据管理里的 DeepSeek Key。

HTTPS 基础地址
  填协议及路径前缀，例如 https://api.example.com/v1。
  App 会按服务追加 /chat/completions、/search、/fetch、/asr 或 /tts。
  聊天的基础地址应填到 /v1 为止，示例最终请求是
  https://api.example.com/v1/chat/completions。实际前缀以提供商文档为准。
  自定义地址须使用有效 HTTPS 证书，并允许 Android WebView 跨域访问。
  地址里不要放用户名、密码、查询参数、URL 片段或 API Key。

模型 ID
  仅第三方聊天需要填。输入服务商文档列出的精确 ID，保留大小写、连字符和前缀。
  例如 OpenCode Zen 的 deepseek-v4-pro。这个 ID 只适用于提供该模型的服务商。
  需要确认该模型支持流式 OpenAI Chat Completions（SSE）。

API Key
  每项服务独立填写。预设的第三方服务需要 Key。自定义服务无需鉴权时可留空。
  填密钥本身，App 会添加 Authorization: Bearer 请求头。
  “已保存”表示配置通过本地格式检查。实际权限、额度与模型可用性以请求结果为准。

三、五项服务怎么选
------------------
聊天模型
  可选 DeepSeek、OpenCode Zen、硅基流动或自定义。
  第三方聊天在此版本支持流式文本。要发送附件，请切回 DeepSeek，并选择支持
  所需文件类型的模型。第三方模型使用提供商默认的思考设置。
  OpenCode 的模型走不同协议，使用本 App 接入时请选择支持 Chat Completions 的模型。

网页搜索
  可选 DeepSeek、Tavily 或兼容 DeepSeek Search 的自定义接口。
  输入问题并打开「联网搜索」时，标准模式会为当前问题发起一次独立检索。
  DeepSeek 兼容接口接收 POST /search，返回 results 数组及 URL、标题和摘要。

读取链接
  可选 DeepSeek、Tavily 或兼容 DeepSeek Fetch 的自定义接口。
  标准模式开启联网时，如果问题含有公开 HTTP(S) 链接，优先读取第一个链接。
  DeepSeek 兼容接口接收 POST /fetch，输入 url，返回 title 和 content。
  Tavily 预设会使用 /extract。回答里的「联网来源」可以展开。
  关闭联网按钮会同时停用网页搜索与读链接。检索失败时仍会继续生成回答。

语音输入（ASR）
  把录音转成文字。可选 DeepSeek 或兼容其 ASR 的自定义接口。
  POST /asr 接收 multipart/form-data，录音字段为 file，返回包含 text 的 JSON。

朗读（TTS）
  把回复文字转换为语音。可选 DeepSeek 或兼容其 TTS 的自定义接口。
  POST /tts 接收 text、voice_id、format、filter_markdown。
  响应须为 24 kHz、16 位小端、单声道裸 PCM 音频流。音色在「通用设置」里选择，
  自定义接口须能处理应用发送的 stella 或 tide。

一个可用的搭配是用硅基流动聊天，用 Tavily 搜索和读链接，语音两项保留 DeepSeek。
仅使用聊天时，可以先不配其他服务。不同提供商会各自计费和限流。
发送给聊天提供商的数据可包含会话文本、系统提示词及本轮检索摘要；语音输入会
上传本次录音，朗读会发送要念的文本。各项密钥保存在本机，请勿分享截图里的密钥。

四、实验线里的其他参数
----------------------
模型（DeepSeek）
  使用内置 DeepSeek 聊天时，可在 Flash 与 V4 Pro 之间切换。图片输入使用 Flash。

思考强度
  内置 DeepSeek 提供「关闭、低、高、最大」。强度更高可能需要更多时间和输出额度。
  用第三方聊天时由提供商决定，App 不发送 DeepSeek 的思考强度参数。

上下文窗口（tokens）
  这是 App 判断何时压缩旧对话的本地预算。它不会提升服务端上下文上限。
  内置 DeepSeek 自动预算为 1,000,000 tokens。第三方聊天的自动预算为 128,000，
  这是 App 的默认值。选择「自定义」时须输入大于 98,304 的数字。
  若模型窗口比应用预算小，长对话仍可能被拒。遇到上限时可以开启新对话，
  或用 /compact 先对已有历史做摘要。压缩请求也会调用当前聊天提供商。
  单条消息长度和多轮总窗口是两回事，服务端可能分别设上限。

安全护栏
  全家桶提供「默认检查」和「加强检查」。标准 API 不发送此 App 的安全等级参数。
  标准模式下，请求仍按所用服务商的规则处理。

提示词预设
  「预设名称」是本机列表里的名字。「系统提示词」会随聊天请求发给所选模型。
  点「保存并启用」后，用于后续新回复。适合设置回答语言、篇幅和任务角色。

五、常见问题
------------
401/403：检查发请求的那一项 Key、账号权限与模型权限；各服务的 Key 独立保存。
404：检查基础地址是否多填了一段路径，确认模型 ID 与请求协议匹配。
429 或余额不足：查看对应提供商的限额和余额，再重新发起请求。
网络或协议错误：检查 HTTPS、跨域支持，以及聊天接口是否确实返回流式 SSE。
提示附件不可用：移除草稿里的附件后再发，或切回支持该文件类型的 DeepSeek 模型。
看不到服务提供商：检查「请求模式」是否为「标准 API」。
已打开联网但没来源：先确认搜索或读链接配置已保存。有公开网址时优先用读链接服务。

供应商配置备份
打开「实验线设置 → 服务提供商 → 供应商配置备份」导入或导出 ZIP。配置包含供应商资料、模型和服务分配，API Key 不进入文件。配置导入会保留已有记录，导入自定义供应商后请填入密钥并确认服务分配。

聊天自动备份
在 Android 的「数据管理 → 自动备份」选择日期并点「恢复备份」。确认后会先校验备份，再替换当前会话和附件。设备保留最近三份自动备份。清除应用数据或卸载前，可先通过「导出所有历史对话」把备份保存到应用外。
